# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2.0.0] - 2025-01-19

### Added

- 🤖 Dual personality system (Fluffy Bot & Cool Boy)
- 🧠 Learning system with skill leveling (beginner → intermediate → expert)
- 🔧 Project auto-detection and tracking
- 🗣️ Voice output with text-to-speech
- 📊 5 export formats (JSON, TXT, HTML, Markdown, Clipboard)
- 🎨 Preference dashboard modal
- 🔧 Project management modal
- 💾 localStorage persistence
- 🎤 Voice toggle button
- 📈 Progress tracking for projects
- 🔔 Smart project follow-up reminders
- 🌐 40+ custom keyword responses
- 📚 Technical knowledge database (6 domains)
- 🎯 Context-aware responses
- 📱 Responsive mobile design
- ✨ Smooth animations and transitions
- 🔄 Mode switching with context preservation

### Technical

- Pattern matching conversation engine
- Modular JavaScript architecture
- Zero dependencies
- No backend required
- Browser-based storage
- Web Speech API integration
- Fetch API for training data
- ES6+ JavaScript

### Documentation

- Comprehensive README.md
- Contributing guidelines
- MIT License
- Usage examples
- Customization guide
